### Run

Upload file(s) to S3 from the local file system.

| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| `bucket` | Yes | string | S3 Bucket |
| `save_as` | No | string / array | S3 file key(s) to upload as. Include directory in this path. |
| `file` | No | string / array | File or list of files to upload. Accepts strings or pathlib.Path objects. |
| `endpoint_url` | No | string | Override the S3 host for alternative S3 storage providers. |
| `aws_access_key_id` | No | string | Set the access key. Can also be set as an environment variable |
| `aws_secret_access_key` | No | string | Set the access secret. Can also be set as an environment variable |
| `if` | No | string | Specify a condition to determine if this will execute or not. e.g. $&#123;variable&#125; == 1. Recipe variables $&#123;variable&#125; are parameterized and may be used within the statement. |
