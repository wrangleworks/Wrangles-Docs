## GUID

Create a column with a GUID (Globally Unique Identifier).

### Examples

#### Creating a New GUID Column

##### Recipe

```yaml
wrangles:
  - create.guid:
      output: GUID Column

  # OR

  - create.uuid:
      output: GUID Column
```
