## Stock Wrangles

Stock Wrangles are included when installing the Data Wrangles Excel add-in. Follow the links below to learn more about each type.

-   [Extract *Identify and extract meaningful information from unstructured text*](/xl/extract)
-   [Format *Quickly reformat data*](/xl/format)
-   [Standardize *Wrangles to Standardize text data*](/xl/standardize)
-   [Classify *Predict which categories items belong to*](/xl/classify)
-   [Translate *Translate text between languages*](/xl/translate)

### New Location

Stock wrangles can now be found found with their diy counterparts in My Wrangles and will be found here **exclusively** at an upcoming date. Each stock wrangle is tagged with "stock" and its type. Use the filter option to only see stock wrangles.
