# S3 Download Files

### Recipe
```yaml
run:
  on_start:
    - s3.download_files:
        bucket: s3-bucket
        key: example.csv
```

### Function
```python
from wrangles.connectors import s3
df = s3.download_files.run(
      bucket='bucket',
      key='key',
      file = 'example.csv',
)
```
