# S3

> Added **v0.5**

The S3 connector supports writing files to & from a bucket as well as uploading/downloading.

### Read
### Recipe
```yaml
read:
  - s3:
      bucket: bucket
      file_key: data.csv
      access_key: access_key
      secret_access_key: secret_access_key
```

### Function
```python
from wrangles.connectors import s3
df = s3.read(
      bucket='bucket',
      file_key='data.csv',
      access_key='access_key',
      secret_access_key='secret_access_key'
)
```

> The S3 connector also supports the same optional parameters as the file connector. See the [file connector](/py/connectors/file) for more details.

### Write
### Recipe
```yaml
write:
  - s3:
      bucket: bucket
      file_key: data.csv
      access_key: access_key
      secret_access_key: secret_access_key
```

### Function
```python
from wrangles.connectors import s3

import pandas as pd

df = pd.DataFrame({'Product': ['Example product']})

s3.write(
      df,
      bucket='bucket',
      file_key='data.csv',
      access_key='access_key',
      secret_access_key='secret_access_key'
)
```

> The S3 connector also supports the same optional parameters as the file connector. See the [file connector](/py/connectors/file) for more details.
