# S3 Upload Files

### Recipe
```yaml
run:
  on_success:
    - s3.upload_files:
        bucket: s3-bucket
        file: example.csv
```

### Function
```python
from wrangles.connectors import s3
s3.upload_files.run(
      bucket='bucket',
      file = 'example.csv',
      key='key'
)
```
